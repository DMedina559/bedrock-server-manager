# Extend BSM with plugins

Plugins add automation, notifications, content tools and custom integrations. They run Python code in the manager's environment, so install code from sources you trust.

Start with the [plugin management guide](../plugins/introduction.md) and [bundled plugin descriptions](../features/default_plugins.md). To write a plugin, use the [author guide](../developer/plugins/introduction.md), [typed contracts](../developer/plugins/contracts.md), [API reference](../plugins/plugin_apis.md) and [event reference](../plugins/plugin_events.md).
