# Release notes

The [GitHub release history](https://github.com/DMedina559/bedrock-server-manager/releases) is the authoritative changelog, including prereleases. [PyPI release history](https://pypi.org/project/bedrock-server-manager/#history) lists published package versions.

Select the notes for your installed and target versions. Development documentation can include features not yet available in a published release. Review breaking changes before upgrading databases, plugins or generated clients.

See [upgrade an installation](general/upgrading.md) for backups, service migration, compatibility checks and rollback considerations.
